# Security Policy

## Supported Versions

Only the latest released version of Kimbo receives security updates.

## Reporting a Vulnerability

Please report security vulnerabilities privately by email to
**luca@tescari.dev**. Do not open a public GitHub issue for security reports.

Include a description of the issue, steps to reproduce, and the affected
version. As a solo-maintained project, acknowledgement is best-effort, but
reports will be reviewed as quickly as possible.

## Telemetry

Kimbo integrates optional, opt-in crash reporting via Sentry. It is disabled
unless you enable telemetry in Settings, and Kimbo is fully functional without
it.
